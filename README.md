# regen_auto_CRM

An affordable field-service CRM with online booking hosted on a subdomain of the
business's own website. Built for service businesses that are just starting out.

**Status:** research and planning. No application code yet.

- `BRIEF.md`: team brief, ground rules, goals and current status
- `research/transcripts/`: transcripts and descriptions of the 20 FielddEDU tutorial videos
- `research/site/llms.txt`: fieldd.co's published product and pricing summary
